This Excel file compiles the main information on the eukaryotic cif genes retained for analysis, from the identification of bona fide cif genes among cif-like candidates to their phylogenetic classification and the analysis of their genomic environment.

The table notably provides two identifiers for each cif-like sequence: the BLAST-hit accession and the Selected-accession, corresponding to the final accession used to obtain the protein sequence, either by manual translation (“M”) or automatic annotation (“A”).
