This Excel file compiles the main information on the eukaryotic _cif_-like sequences retained for analysis, from the identification of true _cif_ genes among _cif_-like candidates to their phylogenetic classification and the analysis of their genomic environment.

The table notably provides two identifiers for each _cif_-like sequence: the BLAST-hit accession and the Selected-accession, corresponding to the final accession used to obtain the protein sequence, either by manual translation (“M”) or automatic annotation (“A”).
