The [cif_sequences](https://github.com/Nykfel/ARTHROCIF/tree/main/2.%20Phylogeny/Complete%20cif%20phylogeny/Data/cif_sequences) folder contains all sequences initially considered for the analysis. It separates the sequences retained for phylogenetic reconstruction from those excluded because their inclusion would have caused excessive loss of informative positions.

The [domains_sequences](https://github.com/Nykfel/ARTHROCIF/tree/main/2.%20Phylogeny/Complete%20cif%20phylogeny/Data/domains_sequences) folder contains the unaligned sequences of the different Cif domains used for the phylogenetic analyses.

The [Alignement_final](https://github.com/Nykfel/ARTHROCIF/tree/main/2.%20Phylogeny/Complete%20cif%20phylogeny/Data/Alignement_final) folder contains the processed alignments, in which only columns with a maximum of three gaps were retained. Domain alignments were concatenated when required.
